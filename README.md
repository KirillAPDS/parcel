# Parcel Tracker

## Описание
Parcel Tracker — это консольное приложение на Go для отслеживания посылок.  
Программа использует базу данных SQLite, предоставляет функции для добавления, обновления, просмотра и поиска информации о посылках.  
Подходит для локального использования или как базовый шаблон для дальнейшего расширения (например, REST API).

## Функционал
- Хранение информации о посылках в базе данных SQLite.
- Добавление и обновление записей.
- Получение списка всех посылок или поиск по ID.
- Автоматическое тестирование с использованием встроенного пакета `testing`.

## Структура проекта
```
.
├── go.mod           # Модуль и зависимости Go
├── go.sum           # Контрольные суммы зависимостей
├── main.go          # Точка входа в приложение
├── parcel.go        # Основная логика работы с посылками
├── parcel_test.go   # Тесты
└── tracker.db       # База данных SQLite
```

## Требования
- Go 1.20+
- SQLite 3

## Установка и запуск
```bash
# Клонировать репозиторий
git clone https://github.com/KirillAPDS/parcel.git
cd parcel

# Запуск приложения
go run main.go
```
## Пример работы

**Ввод:**
```
Добавить посылку:

Статус: В пути
```
**Вывод:**

